# 文档编写与审查标准

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 三问校验

1. 开发 Agent 能不能直接开发？
2. 测试 Agent 能不能直接测试？
3. 审查 Agent 能不能定位责任端和接口？

## 前端页面写法

每个页面必须写：入口、展示字段、操作按钮、调用接口、请求字段、响应字段、状态枚举、异常提示、loading、空状态、防重复提交、实时刷新、验收标准。

## 接口写法

每个接口必须写：调用端、Token、权限、参数、响应、错误码、状态流转、幂等、审计、领域事件、前端页面、测试用例。

## 手动审查要求

每个阶段都必须执行 `手动审查与测试.md`，所有 P0/P1 必须关闭后才能进入下一阶段。
