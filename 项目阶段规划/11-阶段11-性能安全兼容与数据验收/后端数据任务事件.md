# 阶段11-性能安全兼容与数据验收 后端数据、任务与事件

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 后端模块

- observability
- security
- rate-limit
- backup
- report
- export
- ops

## 核心数据表 / 数据域

- metrics
- alerts
- slow_query_log
- security_event
- backup_record
- export_task
- audit_log

## 定时任务 / 后台任务

- 压测数据清理。
- 慢查询巡检。
- 备份恢复演练。
- 日志归档。
- 安全扫描。

## 领域事件

- AlertTriggered
- BackupCompleted
- SecurityEventDetected
- SlaBreached
- ExportCompleted

## 后端实现约束

- 外卖订单和跑腿订单必须独立表、独立状态机、独立日志。
- 所有资金、退款、提现、结算、处罚必须记录流水和审计日志。
- 定时任务必须支持分布式锁、幂等、补偿和失败重试。
- 领域事件必须记录 eventId、bizType、bizId、payload、status、retryCount、errorMessage。
- 第三方调用必须经过适配层，业务模块不得直接散落调用 SDK。
