# 阶段10-四端联调-接口状态消息资金 接口契约清单

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 全局接口规范

统一前缀：用户端 `/api/v1/c/**`，商家端 `/api/v1/m/**`，骑手端 `/api/v1/r/**`，平台 Web `/api/v1/admin/**`，公开 `/api/v1/pub/**`，第三方回调 `/api/v1/callback/**`。各端仅使用对应 Token：用户端只用 `Customer-Token`，商家 Android/iOS APP 只用 `Merchant-Token`，骑手 Android/iOS APP 只用 `Rider-Token`，平台 Web 只用 `Admin-Token`。

## 本阶段接口详情

### GET /api/v1/c/orders/{bizType}/{orderId}/timeline

- 接口名称：用户端订单时间线
- 调用端：用户端小程序 / Android APP / iOS APP
- 鉴权 Token：Customer-Token
- 权限点：用户只能查询自己的外卖/跑腿订单时间线。
- 使用页面/场景：用户订单详情
- 请求字段：bizType、orderId
- 响应字段：timeline、currentStatus、availableActions
- 状态/枚举：外卖使用外卖订单状态机，跑腿使用跑腿订单状态机，不允许混用。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；需要支持分页或增量游标时不得改变业务状态。
- 审计日志：记录 traceId、operatorType、operatorId、targetType、targetId、ip、deviceId、createdAt。
- 前端对接注意：页面必须处理 loading、空状态、错误提示和 token 过期跳转。

### GET /api/v1/m/food-orders/{orderId}/timeline

- 接口名称：商家端外卖订单时间线
- 调用端：商家 Android APP / iOS APP
- 鉴权 Token：Merchant-Token
- 权限点：商家只能查询自己店铺的外卖订单，不支持跑腿订单。
- 使用页面/场景：商家 Android/iOS APP 订单详情
- 请求字段：orderId
- 响应字段：timeline、currentStatus、allowedMerchantActions
- 状态/枚举：仅外卖订单状态机。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；不得改变订单状态。
- 审计日志：记录 traceId、merchantId、storeId、orderId、ip、deviceId、createdAt。
- 前端对接注意：商家端不得展示跑腿处理入口。

### GET /api/v1/r/tasks/{taskId}/timeline

- 接口名称：骑手端任务时间线
- 调用端：骑手 Android APP / iOS APP
- 鉴权 Token：Rider-Token
- 权限点：骑手只能查询自己可接、已接、已分配的任务时间线。
- 使用页面/场景：骑手 Android/iOS APP 当前任务详情
- 请求字段：taskId
- 响应字段：timeline、taskStatus、orderBizType、allowedRiderActions
- 状态/枚举：外卖配送任务和跑腿任务分别引用各自状态机。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；不得改变任务状态。
- 审计日志：记录 traceId、riderId、taskId、ip、deviceId、createdAt。
- 前端对接注意：离线或未审核骑手进入任务页必须展示无权限原因。

### GET /api/v1/admin/orders/{bizType}/{orderId}/timeline

- 接口名称：平台端订单时间线
- 调用端：平台管理 Web
- 鉴权 Token：Admin-Token
- 权限点：管理员必须具备订单详情查看权限，并受数据范围限制。
- 使用页面/场景：平台 Web 订单详情 / 订单日志
- 请求字段：bizType、orderId
- 响应字段：timeline、currentStatus、operatorLogs、dispatchLogs、paymentLogs
- 状态/枚举：按 bizType 分别返回外卖或跑腿状态机。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；不得改变订单状态。
- 审计日志：记录 traceId、adminId、orderId、bizType、ip、createdAt。
- 前端对接注意：敏感字段必须脱敏，导出需走导出权限。

### GET /api/v1/c/payments/{payOrderId}

- 接口名称：用户端支付状态查询
- 调用端：用户端小程序 / Android APP / iOS APP
- 鉴权 Token：Customer-Token
- 权限点：用户只能查询自己的支付单。
- 使用页面/场景：支付结果页
- 请求字段：payOrderId
- 响应字段：payStatus、paidAt、amountFen、channel
- 状态/枚举：支付状态 `WAIT_PAY / PAYING / PAID / FAILED / CLOSED / REFUNDING / REFUNDED`。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；不得创建新支付单。
- 审计日志：记录 traceId、customerId、payOrderId、ip、deviceId、createdAt。
- 前端对接注意：轮询支付结果必须设置最大次数，失败后提供重新支付入口。

### GET /api/v1/admin/payments/{payOrderId}

- 接口名称：平台端支付状态查询
- 调用端：平台管理 Web
- 鉴权 Token：Admin-Token
- 权限点：管理员必须具备支付单查看或财务对账权限。
- 使用页面/场景：平台 Web 支付单详情 / 对账详情
- 请求字段：payOrderId
- 响应字段：payStatus、paidAt、amountFen、channel、thirdPartyTradeNo、callbackLogs
- 状态/枚举：支付状态 `WAIT_PAY / PAYING / PAID / FAILED / CLOSED / REFUNDING / REFUNDED`。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：查询接口不要求 Idempotency-Key；不得改变支付单状态。
- 审计日志：记录 traceId、adminId、payOrderId、ip、createdAt。
- 前端对接注意：第三方流水和用户敏感信息按权限脱敏展示。

### POST /api/v1/callback/payments/{channel}

- 接口名称：支付回调
- 调用端：第三方回调
- 鉴权 Token：回调验签
- 权限点：第三方支付渠道白名单、回调签名、时间戳/nonce 防重放、第三方流水号去重。
- 使用页面/场景：支付回调处理
- 请求字段：第三方原始报文、签名、流水号
- 响应字段：SUCCESS/FAIL
- 状态/枚举：以后端阶段状态机枚举为准，前端不得硬编码中文状态。
- 错误码：`INVALID_PARAM`、`UNAUTHORIZED`、`FORBIDDEN`、`DATA_NOT_FOUND`、`STATUS_INVALID`、`DUPLICATE_REQUEST`、`THIRD_PARTY_ERROR`
- 幂等要求：写操作必须支持 `Idempotency-Key`；重复请求返回同一业务结果，不重复扣款、不重复写业务变更。
- 审计日志：记录 traceId、operatorType、operatorId、targetType、targetId、beforeStatus、afterStatus、ip、deviceId、createdAt。
- 前端对接注意：页面必须处理 loading、空状态、错误提示、防重复点击和 token 过期跳转。

- 接口名称：消息订阅/设备绑定

- 鉴权 Token：Customer-Token / Merchant-Token / Rider-Token

- 使用页面/场景：APP 启动、消息设置

- 审计日志：记录 traceId、operatorType、operatorId、targetType、targetId、beforeStatus、afterStatus、ip、deviceId、createdAt。
