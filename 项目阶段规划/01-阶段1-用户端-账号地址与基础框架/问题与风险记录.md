## P2 重要级

- [ ] **[STAGE-0 遗留] admin-web 生产构建失败**
  - 文件：`apps/admin-web/src/utils/request.ts`(以及任何从 `@o2o/contracts` 命名导入的文件)
  - 问题：`packages/contracts` 用 `tsconfig module=CommonJS` 编译,产物 `dist/index.js` 通过 `__exportStar` 重导出。Vite/Rollup 在做 ESM 静态分析时无法跨 CJS 重导出追踪命名导出 → 报 `"Header" is not exported`。
  - 复现:在 commit `29108ae`(Stage 0 终态)运行 `pnpm --filter @o2o/admin-web build` 即可触发,与 Stage 1 改动无关。
  - 影响:admin-web 生产 vite build 不可出包;`pnpm -r build` 总闸常红。dev 模式不受影响(vite 走 ESM 直接读 dist);customer-app 用 uni build 不走 vite/rollup,构建正常。
  - 修复标准(T16 之前必修):把 `packages/contracts/tsconfig.json` 改为 `module: "ESNext"` + `moduleResolution: "Bundler"`,或在 `package.json` 补 `"type":"module"` + `"exports"` 双入口(esm/cjs),让 Rollup 能 trace named exports。
  - 责任人:本阶段(在 T16 wave 5 之前修)
  - 复测结果:待修
