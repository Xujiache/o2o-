# 阶段 13 — 生鲜商城与自提

## 阶段目标
将原"外卖配送"模块整体替换为"生鲜商城 + 到店自提",支持称重计价 + 多退少补;
跑腿模块完全保留并物理隔离。

## 范围(已完成)

### 数据模型
- `pickup_point` `pickup_time_slot` `grocery_order` `grocery_order_item` `pickup_verify_log`
- `product` / `cart_item` 字段扩展:`product_type` `pricing_mode` `weight_unit`
  `min_weight_g` `max_weight_g` `unit_price_per_jin` / `pricing_mode_snapshot`
  `estimated_weight_g`
- 类型联动:PaymentOrderBizType / RefundOrderBizType / CouponBizType 全部追加 GROCERY

### 后端
- 5 个新模块:`pickup-point` / `grocery-product` / `grocery-order` / `pickup-verify` / `grocery-weigh`
- `payment.service` 扩展 GROCERY 双阶段(主单 + 差价)
- `grocery-order-expire` SchedulerJob:WAIT_PAY 15min 超时回滚库存 + 释放时段
- 提货码 sha256(code+salt),核销 5/min 失败封禁 + 防重 5s

### 客户端 customer-app
- 首页双入口"生鲜商城 / 跑腿服务"
- `pages/grocery/*` 全套:首页/商品列表/详情/购物车/结算/订单/详情(提货码 + QR)
- 称重商品支持 100g 步进 + 元/斤 显示
- DIFF_PAYING 状态展示差价补付卡片
- 我的订单 Tab 分商城/跑腿;TabBar 主色 #11998E
- 外卖路由 410(后端 middleware 拦截);旧页面 pages.json 已剔除

### 商家端 merchant-app
- 工作台快捷:今日待发货 / 待核销 / 已核销
- 商品 CRUD(fixed/weighed 双表单)+ 自提点 + 时段批量配置
- 核销:扫码 + 6 位手输码 + 流水
- 称重:逐项录克数 + 实时小计 → confirm 分 AUTO_DONE/AUTO_REFUND/NEEDS_DIFF_PAY
- 差价等待轮询 + finalize
- 备货清单聚合视图

### 数据库迁移
- `1718500000000-GroceryProductAndCartFields.ts`
- `1718500100000-GroceryTables.ts`
