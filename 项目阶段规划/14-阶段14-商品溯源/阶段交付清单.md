# 阶段 14 — 商品溯源

## 阶段目标
为生鲜商品提供"批量生成防伪二维码 + 扫码枪节点录入 + 用户端扫一扫全链路查询"
能力,二维码用 HMAC-SHA256 短签防伪造,匿名可扫,扫码日志支持风控。

## 范围(已完成)

### 数据模型
- `trace_batch`(批次)/ `trace_qr`(二维码)/ `trace_record`(节点)/ `trace_scan_log`(扫码日志)
- 节点支持「批次维度」与「单 QR 维度」二选一

### 后端
- 模块:`trace`(单 module + admin + customer 双 controller)
- 异步生成任务(Redis 存进度;chunk=500 批写;支持 1-10000 单批)
- CSV 索引导出(qr_code + short_sig 16chr + URL)供商家批量出图
- 客户端扫码:HMAC 验签 + 同 IP 30/min 限频 + 匿名可访问 + 异步写日志
- TRACE_SECRET 走 `.env`

### 平台后台 admin-web
- 菜单组"溯源中心"4 子菜单
- 视图:BatchList / BatchCreate / BatchDetail / QrLookup / QrDetail / RecordCreate / Stats
- BatchDetail 异步生成 + 1.5s 轮询进度 + CSV 下载
- QrLookup autoFocus 扫码枪输入 + 最近 10 条历史
- QrDetail 双时间轴(QR 专属节点高亮 + 批次维度只读)
- 权限点:`admin:menu:trace` `admin:trace:batch:write` `admin:trace:qr:generate`
  `admin:trace:qr:export` `admin:trace:record:write`

### 客户端 customer-app
- `pages/trace/scan.vue` 入口(调 uni.scanCode)
- `pages/trace/detail.vue?code=&sig=` 时间轴展示商品 + 批次 + 节点 + 附件

## 验收清单

### 必须项
- [ ] `.env` 配 `TRACE_SECRET`
- [ ] admin-web 能新建批次 + 异步生成 N 个二维码(进度条)
- [ ] 下载 CSV 拿到 qr_code + short_sig + URL,可批量出 PNG
- [ ] 扫码枪在 QrLookup 页面 autoFocus → 输入 6+ 位 → 跳详情
- [ ] 录入节点支持批次/QR 双维度 + 附件
- [ ] 客户端扫一扫 → 验签通过 → 显示时间轴
- [ ] 伪签 / 错码 → 404
- [ ] 同 IP 60s 内扫码 ≥30 次 → 限流

### 可选项
- [ ] 安装 `qrcode` + `archiver`,启用 ZIP/PDF 后端打包下载(目前仅 CSV)
- [ ] 单测:trace.service 签名验签 + 限频路径
- [ ] 后续接入存证服务(蚂蚁链等)将节点 hash 上链

## 安全声明
- 二维码 URL 含短签;服务端用 SECRET 验签;短签前 16 位入 URL,后端比对
- 同 IP 限频接 RateLimitGuard;异常扫码可走 risk_exception_log
- 节点录入需 `admin:trace:record:write`,全部走 AuditInterceptor
