# 全局状态机与业务规则

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 强制时效规则

- 用户下单 15 分钟未支付：自动关单，释放库存或调度资源。
- 外卖订单商家 5 分钟未接单：提醒商家。
- 外卖订单商家 10 分钟未接单：自动取消并全额退款。
- 跑腿订单 3 分钟无骑手接单：自动加价推送。
- 跑腿订单 10 分钟无人接单：自动取消并全额退款。
- 默认 T+1 自动结算，平台可自定义周期。

## 外卖订单状态

`WAIT_PAY -> PAID_WAIT_MERCHANT -> MERCHANT_ACCEPTED -> PREPARING -> READY_FOR_PICKUP -> RIDER_ASSIGNED -> PICKED_UP -> DELIVERING -> DELIVERED -> COMPLETED`

异常：`CANCELLED`、`REFUNDING`、`REFUNDED`、`AFTER_SALE`。

## 跑腿订单状态

`WAIT_PAY -> PAID_WAIT_RIDER -> PRICE_INCREASED -> RIDER_ASSIGNED -> WAIT_PICKUP -> PICKED_UP -> DELIVERING -> WAIT_CONFIRM -> COMPLETED`

异常：`CANCELLED`、`REFUNDING`、`REFUNDED`、`AFTER_SALE`。

## 审查要求

- 状态码以后端枚举为唯一权威。
- 四端不得各自维护不同状态码。
- 每个状态必须写 allowedActions 和 nextStates。
