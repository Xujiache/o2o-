# 阶段4-平台管理端Web-审核管控与基础配置 状态机与业务规则

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 本阶段业务规则

- 后台所有敏感数据脱敏。
- 权限分菜单权限和按钮权限。
- 审核、禁用、费率、第三方配置必须写操作日志。
- 平台 Web 不提供商家日常经营替代入口。

## 全局强制规则

- 用户下单 15 分钟未支付：自动关单并释放库存或调度资源。
- 外卖订单商家 5 分钟未接单：系统提醒。
- 外卖订单商家 10 分钟未接单：自动取消并全额退款。
- 跑腿订单 3 分钟无骑手接单：自动加价推送。
- 跑腿订单 10 分钟无人接单：自动取消并全额退款。
- 骑手收益 = 基础酬劳 + 距离补贴 + 时效奖励 - 违规扣款。
- 默认 T+1 自动结算，平台可配置周期。

## 状态审查要求

- [ ] 状态码以后端枚举为唯一权威。
- [ ] 前端不得自造状态码或用中文文案反推状态。
- [ ] 每个状态必须定义允许操作。
- [ ] 每个状态必须定义 nextStates。
- [ ] 非法状态流转必须返回 STATUS_INVALID。
- [ ] 状态变更必须写订单日志或业务日志。
