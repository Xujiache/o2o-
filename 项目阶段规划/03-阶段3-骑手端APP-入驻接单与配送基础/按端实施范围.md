# 阶段3-骑手端APP-入驻接单与配送基础 按端实施范围

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 用户端：微信小程序 / Android APP / iOS APP

- 本阶段不涉及用户端新增功能，若消费接口则按接口契约联调。

## 商家端：Android APP / iOS APP

- 本阶段不涉及商家端新增功能；仍需确认无商家 Web、无商家小程序。

## 骑手端：Android APP / iOS APP

- 手机号注册、身份证+人脸实名、健康证、车辆信息、配送区域。
- 审核进度、失败原因、重新提交。
- 上线/下线、接单区域、服务等级、评分、接单量、违规记录。
- 接单大厅基础展示外卖/跑腿订单，显示距离、酬劳、时效、地址。
- 定位权限、设备绑定、当前位置上报。

## 平台管理端：Web 后台

- 骑手资质审核、账号启停、信用分、配送范围、接单上限。

## 端间数据流

- 用户端产生订单、支付、售后、评价和地址数据。
- 商家端只处理外卖相关店铺、商品、订单、售后、营收数据。
- 骑手端处理外卖配送任务和跑腿任务，不处理商家经营数据。
- 平台 Web 只做审核、配置、调度、仲裁、数据和风控，不替代商家 Android/iOS APP 的经营动作。

## 边界审查点

- [ ] 商家端没有 Web 后台规划。
- [ ] 商家端没有小程序规划。
- [ ] 跑腿订单没有进入商家端处理流程。
- [ ] 平台 Web 没有替代商家接单、商品维护、商家日常经营。
- [ ] 用户端、商家端、骑手端、平台端 Token 和权限隔离。
