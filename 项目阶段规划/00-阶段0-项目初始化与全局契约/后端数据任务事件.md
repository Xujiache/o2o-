# 阶段0-项目初始化与全局契约 后端数据、任务与事件

> 商家端仅 Android APP / iOS APP，禁止规划商家 Web 后台、商家小程序。外卖订单与跑腿订单必须独立订单体系、独立状态机、独立计价、独立退款规则。

## 后端模块

- gateway
- auth
- common-config
- dict
- file
- integration-gateway
- audit-log
- system
- risk

## 核心数据表 / 数据域

- sys_dict
- sys_config
- sys_error_code
- sys_role
- sys_permission
- sys_audit_log
- file_object
- third_party_config
- idempotency_record

## 定时任务 / 后台任务

- 清理过期验证码和幂等记录。
- 归档审计日志。
- 第三方失败请求重试。
- 配置变更发布缓存刷新。

## 领域事件

- ConfigChanged
- PermissionChanged
- FileUploaded
- ThirdPartyCallbackReceived
- AuditLogCreated

## 后端实现约束

- 外卖订单和跑腿订单必须独立表、独立状态机、独立日志。
- 所有资金、退款、提现、结算、处罚必须记录流水和审计日志。
- 定时任务必须支持分布式锁、幂等、补偿和失败重试。
- 领域事件必须记录 eventId、bizType、bizId、payload、status、retryCount、errorMessage。
- 第三方调用必须经过适配层，业务模块不得直接散落调用 SDK。
