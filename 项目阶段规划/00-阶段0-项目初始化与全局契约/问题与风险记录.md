## P2 重要级（全部已修复）

| 编号 | 文件/接口 | 问题 | 影响 | 修复 | 责任人 | 复测结果 |
|---|---|---|---|---|---|---|
| P2-1 | `deploy/docker-compose.dev.yml` | Windows 主机 MySQL 服务占用 3306 | dev MySQL 容器启动失败 | 改 3307→3306 端口映射；`.env` 写 `MYSQL_PORT=3307` | 建设者 | T05 后端启动 + 11 张表 migrate 全部成功 |
| P2-2 | `apps/server/tsconfig.json` 跨包 paths | TS paths 把共享包源码并入 server 编译，致 `dist/` 输出层级错乱 | `nest build` 后 `dist/main.js` 路径错，runtime 找不到入口 | 移除跨包 paths，共享包 `tsc -p tsconfig.json` 各自 build 到 `dist/`，server 走 workspace 主入口 | 建设者 | server `pnpm build` + `pnpm start` 双双通过 |
| P2-3 | `PermissionGuard` 跨模块注入 | `SystemModule` 内 `@UseGuards(PermissionGuard)` 找不到 `SysRoleRepository`；nest DI 报错 | `/admin/integrations/health` 返回 500 | 创建 `@Global AuthEntitiesModule` re-export `TypeOrmModule.forFeature([SysRole, SysPermission, SysRolePermission])` | 建设者 | admin 接口 200，单测覆盖 |
| P2-4 | `apps/admin-web/vite.config.ts` | `unocss/vite` 是 ESM-only 包，被 require() 加载失败 | admin-web dev 启动失败：`"unocss/vite" resolved to an ESM file` | 给 `apps/admin-web/package.json` 加 `"type":"module"` | 建设者 | dev server 在 :8083 ready in 2544ms |
| P2-5 | Windows 下 dev server 进程 | nest/vite 子进程不响应 SIGTERM(Windows 限制)，TaskStop 父进程后子进程仍占端口 | 多端 dev 并跑时 8083-8087 全被占，端口分配错乱 | 使用 `Stop-Process -Id <PID> -Force` 显式 kill；项目记忆 `project_o2o_environment.md` 已记录 | 建设者 | netstat 验证端口释放 |
