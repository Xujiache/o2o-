# 骑手端 Service 说明

这些 service 统一封装定位、轨迹上报、推送和后台保活能力，页面层通过接口调用，不直接依赖平台实现细节。

| 文件              | 职责                            |
| ----------------- | ------------------------------- |
| `location.ts`     | 前台/后台定位                   |
| `trace-upload.ts` | 轨迹批量上传                    |
| `push.ts`         | 推送 clientId/cid 绑定          |
| `keepalive.ts`    | Android 前台服务 / iOS 后台模式 |

## 约定

- 业务层只依赖 service 接口。
- 定位失败时允许使用兜底坐标，避免任务流程中断。
- 轨迹、推送和保活能力由 service 内部负责平台差异。
