# 阶段 GR-0 — 生鲜自营商城改造 · 契约对齐

> GR = Grocery。区别于历史 stage 0~10 的"外卖+跑腿"建设阶段。
> GR 阶段是把"外卖+多商户"那条业务线整体重做为"平台自营生鲜商城（按斤计价 + 多自提点 + 一鸡一码溯源 + 估重复核多退少补）"。
> 跑腿 errand 与骑手 rider 整条线**严格保留不动**。

## 强制边界（任何 GR 阶段不得越界）

- 保留：`apps/server/src/modules/errand-*`、`errand-*.entity.ts`、`apps/customer-app/src/pages/errand/`、所有 rider 模块/表/页面
- 废弃：`apps/server/src/modules/merchant-*`（除 merchant-auth 改"自营运营员登录"外）、`food-order` / `cart` / `coupon-*` 旧链路、`apps/customer-app/src/pages/food/`、商家端入驻/资质/分账
- 新增：5 个后端模块（pickup-point / grocery-product / grocery-order / traceability-archive / traceability-qrcode）+ 4 端配套页面

## 6 项产品决策（已在 Plan 阶段经用户确认，本文档据此设计）

| 项       | 决策                                                             |
| -------- | ---------------------------------------------------------------- |
| 跑腿业务 | 保留完整（独立业务线，与生鲜并存）                               |
| 改造起点 | 当前 main 全新设计，**不复用** `archive/grocery-experiment` 分支 |
| 物流模式 | **全自提**，骑手 rider 零参与生鲜                                |
| 计价模式 | **下单估重预付 + 拣货复核 + 多退少补**                           |
| 溯源粒度 | **一鸡一码**（每只独立二维码 + 独立档案）                        |
| 自提点   | **多自提点 + 用户下单时按距离选点**                              |

## 7 阶段交付顺序

| 阶段               | 内容                                                                     | 相对工作量 |
| ------------------ | ------------------------------------------------------------------------ | ---------- |
| **GR-0**（本阶段） | 契约对齐 + schema 评审 + UI 线框 + 状态机 + 边界规则（**不写业务代码**） | 0.5        |
| GR-1               | 多商户废弃 + 自提点基座                                                  | 0.8        |
| GR-2               | 按斤计价商品 + 商家端管理                                                | 1.2        |
| GR-3               | grocery-order 下单 + 估价支付                                            | 1.0        |
| GR-4               | 拣货 + 称重 + 多退少补（最复杂）                                         | 2.0        |
| GR-5               | 一鸡一码二维码 + 溯源档案                                                | 1.5        |
| GR-6               | 商家端收口为自营运营员后台                                               | 0.5        |
| GR-7               | 四端联调 + 演示 seed + 410 兜底 + FINAL                                  | 0.8        |
